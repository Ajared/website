# Site Architecture — ajared.ca

## Stack
- **Content:** Semantic XML (.xml files)
- **Presentation/Logic:** XSLT 1.0 (site-renderer.xslt), Vanilla CSS, Vanilla JS
- **Compiler:** xsltproc (Unix standard)
- **Typography:** iA Writer Quattro S
- **Forms:** Formspree
- **Hosting:** GitHub Pages
- **Booking:** cal.com/ajared
- **Repo:** Git, branch = main

---

## CRITICAL EDITING RULES

1. **NEVER edit .html files** — they are entirely auto-generated by the build script
2. **Always edit .xml files** — these are the source of truth for content
3. To preview locally: open the .xml file in a browser (native XSLT renders it instantly)
4. To deploy: `git commit` → pre-commit hook auto-runs `./scripts/build.sh` → compiles all .xml → .html → bundles into commit
5. To push live: `git push origin main` (must be done from Chu's machine — Claude's sandbox has no internet access to GitHub)

## XML Component Reference

Common XML tags used in page files:

| Tag | Purpose |
|-----|---------|
| `<Page id="..." title="...">` | Root element, sets page identity |
| `<Schema>` | JSON-LD structured data (schema.org) |
| `<Header>` | Top nav bar |
| `<Nav active="...">` | Navigation, highlights active item |
| `<Hero>` | Homepage hero section |
| `<CapabilityHero>` | Capability page hero |
| `<OfferGrid>` / `<Offer>` | Homepage offer cards |
| `<PageBody>` / `<Section>` | Body content sections |
| `<Offerings>` / `<Offering>` | Service offering cards |
| `<Process>` / `<Step>` | How-we-work steps |
| `<Deliverables>` / `<Row>` | Deliverable checklist items |
| `<CTABlock>` | Call-to-action banner |
| `<CapNav>` | Prev/Next capability navigation |
| `<ContactForm>` | Renders contact form (Formspree) |
| `<SprintForm>` | Renders sprint intake form |
| `<Footer>` | Footer with email + year |

## Deployment Workflow

```
1. Edit .xml file
2. Preview: open .xml in browser
3. git add capabilities/002-ai-product.xml
4. git commit -m "update description"
   → pre-commit hook fires → build.sh compiles .xml → .html
5. git push origin main   ← from Chu's machine only
   → GitHub Pages serves live at ajared.ca
```
