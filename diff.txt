+# Site Architecture — ajared.ca
+
+## Stack
+- **Content:** Semantic XML (.xml files)
+- **Presentation/Logic:** XSLT 1.0 (site-renderer.xslt), Vanilla CSS, Vanilla JS
+- **Compiler:** xsltproc (Unix standard)
+- **Typography:** iA Writer Quattro S
+- **Forms:** Formspree
+- **Hosting:** GitHub Pages
+- **Booking:** cal.com/ajared
+- **Repo:** Git, branch = main
+
+---
+
+## CRITICAL EDITING RULES
+
+1. **NEVER edit .html files** — they are entirely auto-generated by the build script
+2. **Always edit .xml files** — these are the source of truth for content
+3. To preview locally: open the .xml file in a browser (native XSLT renders it instantly)
+4. To deploy: `git commit` → pre-commit hook auto-runs `./scripts/build.sh` → compiles all .xml → .html → bundles into commit
+5. To push live: `git push origin main` (must be done from Chu's machine — Claude's sandbox has no internet access to GitHub)
+
